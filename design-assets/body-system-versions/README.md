# Body-system artwork archive

This folder preserves source material and earlier cardiovascular versions
without copying them into the Care Connect production build.

- system-cardiovascular-master-v5.png in patient/assets/ is the currently
  selected cardiovascular master.
- system-cardiovascular-master-v2.png through v4.png are retained here for
  visual history.
- system-cardiovascular-reference.png is the user-provided reference.
- system-cardiovascular.png is the earlier preliminary draft.
- system-cardiovascular-clean-background-candidate.png is an unapproved
  background-cleanup candidate. It is intentionally not wired to a patient
  page because the image edit changed more anatomy than requested.

All active body maps across the seven systems are educational illustrations,
not diagnostic images. BHW clinical review and final art approval are required
before production release.
